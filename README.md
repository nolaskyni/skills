# Agent Skills

A collection of Agent Skills for extending AI capabilities in learning,
programming, science, and more.

## Available Skills

### Programming

#### `coding-standards`

Guidelines for file structure, formatting, naming, comments, documentation, and
tooling in Markdown, Python, and TypeScript, with configuration files for their
formatters, linters, and type checkers.

#### `collaborative-coding`

Guidelines for working with an agent that writes most of the code, so that the
user can still explain what it does, why it is designed that way, and how it
works.

#### `commit-message-guidelines`

Guidelines for writing commit messages that follow the Conventional Commits
specification, with a few extensions.

### Writing

#### `technical-writing-guidelines`

Guidelines for writing documentation based on the Google developer
documentation style guide, with rules for tone, word choice, symbols, headings,
lists, code in text, and cross-references.

## Installation

```shell
npx skills add nolaskyni/skills
```

## AI Usage

AI assists with drafting, reviewing, refining, and testing Agent Skills, with a
human in the loop.
