# Agent Co-Author Information

## Overview

Use the listed co-author name and email address by default. A name may be
substituted with/on behalf of a permitted variant or the exact name of the model
that made the changes, if that model is known. In either case, retain the email
address listed for the agent product. If the model is unknown, use the default
name. Omit trailers for unlisted agent products; do not invent an identity.
